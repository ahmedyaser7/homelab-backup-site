Homelab Backup is a privately operated, self-hosted utility for creating and storing server backup archives in the owner's Google Drive account. It is not a publicly available file storage or clinical application.

How it works

A small, purpose-built backup workflow

Google Drive access is authorised by the account owner and used by the server's backup job, not by a public website.

01

Create

The privately hosted server generates a backup archive, validates its format and calculates an integrity checksum.

02

Store

rclone uses Google OAuth and the Google Drive API to upload backup files to a configured, private folder in the owner's account.

03

Verify & recover

The server checks the uploaded archive's integrity. The owner may later download it for a manual restore.

Google permissions

Why does this app request Drive access?

Access is requested only to perform backup-related operations: create, list, retrieve, verify and remove older backup files. Depending on the OAuth scope granted, the technical permission may extend beyond the backup folder, but normal operations are confined to the configured backup location.

Files are stored in the owner's Google Drive. The application does not sell Google user data or use it for advertising.

A note about sensitive data

Archives may contain identifiable research or clinical records and application account information. This static website does not display backups or credentials. Backup files are not independently encrypted by the current backup script; Drive permissions must remain private.
