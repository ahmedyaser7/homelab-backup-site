How Homelab Backup accesses, uses and protects Google Drive data.

Last updated: 17 October 2026

1. Who operates this utility?

Homelab Backup is a personal, self-hosted server backup utility operated by the owner of the connected Google account. It is not a consumer-facing cloud storage service. Questions may be directed to the operator through the operator's GitHub profile.

2. Google user data accessed

The utility uses rclone and the Google Drive API, after explicit Google OAuth authorisation, to work with backup objects in a designated Drive folder. This can involve file names, identifiers, file contents and related metadata, including the data needed to upload, list, download, verify and delete those objects.

Google's OAuth consent screen describes the actual Drive permission scope requested. If a broad scope is granted, the token may technically be able to access files beyond the backup folder; ordinary backup scripts limit their operations to the configured destination.

3. How Google data is used

Google Drive access is used to upload full backup archives and checksum files, retrieve or read files to verify integrity, list backup locations when required, and delete this utility's expired scheduled backups according to the configured retention policy. No Google user data is used for personalised advertising, profiling, resale or unrelated analytics.

4. Where data is stored

Backup archives are saved locally on the privately administered server and copied into the owner's private Google Drive account. OAuth access and refresh tokens are stored in the server's protected rclone configuration, not on this public informational website. The website itself contains no login, upload form or backup viewer.

Backup archives may contain personal information, identifiable clinical/research records, activity history and password hashes from the applications being backed up. The current backup process does not apply an additional client-side encryption layer before uploading to Drive. The owner must protect access to both the Drive account and local storage.

5. Sharing and transfer

The utility transfers backup files and related metadata to Google Drive as instructed by the account owner. It does not sell or share Google account data with advertisers, data brokers or unrelated third parties. Files are accessible to parties to whom the account owner independently grants Drive access and to service providers as governed by Google's terms and privacy policy.

6. Retention and deletion

For the Zeus scheduled backup configuration, this utility retains its own local scheduled backups for approximately 30 days and its own corresponding Google Drive backups for approximately 90 days. These retention periods are configuration-specific, not general Google Drive retention limits. Earlier or manually uploaded backups may remain until the owner deletes them. The owner can delete backups in Google Drive and revoke authorisation at any time through Google Account security settings.

7. Security

Google OAuth grants access only after the account owner approves the requested scope. Backup automation operates from the private server. Access to the backup archives, server configuration and Google account should be restricted. The backup job validates archive integrity; validation does not replace confidentiality protections.

8. This informational website

This static site does not ask for Google credentials, access Drive data, set first-party tracking cookies or run advertising scripts. As with ordinary website hosting, the host may process technical request information under its own policies.

9. Google API Services User Data Policy

Use of information received through Google APIs is intended to follow the Google API Services User Data Policy, including its Limited Use requirements. The operator can update this document when the backup workflow or access scope changes.

10. Contact

For questions, deletion requests or concerns, contact the operator through GitHub. Because this is a single-owner application, the connected Google account holder can also remove the app's access directly from their own Google Account.
